# 📝 C# Text Editor - Project

A specialized **Text Editor** application developed as a project for the **BLM0357 Visual Programming** course at **Bursa Technical University**. This application is built using the **C# Windows Forms** framework and features a user-friendly interface for document management and text styling.

---

## 🚀 Key Features

### 📂 File Management
* **Custom Menu**: Includes a MenuStrip for easy navigation.
* **File Operations**: Capability to **Open** and **Save** only `.txt` files.
* **Edit Tools**: Integrated **Copy**, **Paste**, and **Undo** functionality.

### 🎨 Advanced Formatting
* **RichText Control**: Uses a `RichTextBox` for text input and manipulation.
* **Selective Styling**: Change the **Font**, **Size**, and **Color** for the selected text area.

### ⌨️ Interactive Shortcuts
* **Quick Bold**: Supports the **CTRL + B** shortcut to toggle bold styling on selected text.

---

## 🛠️ Requirements & Usage

1. **System**: Windows with .NET Framework/Core installed.
2. **Opening Files**: The editor is restricted to only opening `.txt` formats.
3. **Applying Styles**: Highlight a specific portion of text to change its font or color through the **Format** menu.
4. **Shortcuts**: Highlight text and press `CTRL + B` to instantly make it bold.
